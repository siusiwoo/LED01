# LED01 — 상태 LED (대기 · 작업 · 문제)

AMS 현장실습 두 번째 프로젝트 (9~12일차, 2026.10.29 ~ 11.03)

보드 LED로 🟢 대기 · 🟡 작업 · 🔴 문제 상태를 표시하고, PC 버튼과 보드 스위치 어느 쪽으로든 상태를 바꾸며 계산 문제를 주고받습니다.

## 주요 내용
- 상태 중심 설계: 패킷 · 버튼은 `state`만 바꾸고, 반복문이 `state`를 보고 LED 표시
- PC 시작 → 랜덤 계산 문제 N번 전송(`CMD_CALC 0x10`) → 보드가 + − × ÷ % 계산 (0으로 나누기는 NAK)
- 보드 스위치 ↔ PC 연동 (`LED_WRITE 0x01` 양방향), 🔴에서 3초 길게 누르면 🟢 복귀
- 계산 기록 표(DataGrid) + CSV 저장, 곱하기 결과 2바이트 전송

## 폴더
- `Board/` — 🟩 C (STM32CubeIDE). 작성한 코드는 `Core/Src/main.c`의 `USER CODE` 구역
- `PC/` — 🟦 C# WPF (.NET). 코드는 `MainWindow.xaml.cs`

> `Drivers` 폴더는 용량 때문에 빼 두었습니다. `.ioc` 파일을 STM32CubeMX로 열어 코드를 생성하면 다시 만들어집니다.
